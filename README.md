# Text Classification with PyTorch

## Задача

Классифицировать входящие текстовые ТЗ по 5 категориям:

- Веб-разработка
- Мобильное приложение
- Дизайн
- Аналитика
- Маркетинг

Для каждой категории был создан набор обучающих и тестовых примеров.

## Подход

Для преобразования текста в числовое представление используется TF-IDF.

Полученный вектор передается в небольшую нейронную сеть на PyTorch.

Алгоритм:

1. Подготовить датасет.
2. Разделить данные на train и test.
3. Обучить TF-IDF vectorizer на train-данных.
4. Преобразовать train-тексты в TF-IDF-векторы.
5. Передать векторы в нейронную сеть.
6. Обучить модель с помощью CrossEntropyLoss и Adam.
7. Преобразовать test-тексты с помощью уже обученного TF-IDF vectorizer.
8. Получить предсказания модели.
9. Рассчитать accuracy на тестовой выборке.

## Архитектура модели

TextClassifier состоит из:

Input → Linear(64) → ReLU → Linear(5)

где:

- Input — TF-IDF вектор текста;
- 64 — размер скрытого слоя;
- 5 — количество классов.

## Обучение

Для обучения используется:

- Loss: CrossEntropyLoss
- Optimizer: Adam
- Learning rate: 0.001
- Epochs: 100

## Результаты

На тестовой выборке:

Accuracy: 100%

Модель правильно классифицировала 10 из 10 тестовых примеров.

## Ограничения

Датасет небольшой и был создан вручную, поэтому результат не следует считать показателем качества модели на реальных производственных данных.

Для production-решения потребовался бы существенно больший и более разнообразный датасет, а также отдельная validation-выборка.
